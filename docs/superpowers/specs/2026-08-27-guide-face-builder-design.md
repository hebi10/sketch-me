# 그림판 가이드·얼굴 만들기 디자인

## 작업 대상과 사용자

공개 링크로 방문해 휴대폰 손가락으로 그림을 남기는 친구가 대상이다. 그림 실력이나 참여 의지가 높지 않아도 짧은 시간 안에 얼굴의 특징을 표현하고, 원하는 경우 자유롭게 덧그릴 수 있어야 한다. 화면은 기존 모바일 전용 650px 스케치북 디자인과 `그리기 · 가이드 · 편집` 흐름을 유지한다.

## 목표와 완료 기준

- 기존 `참고사진` 탭을 `가이드`로 바꾸고 `사진 참고`와 `얼굴 만들기`를 한곳에서 제공한다.
- 얼굴형·머리·눈·입·소품을 선택하면 즉시 한 얼굴로 조합되며, 조합 위에 자유롭게 그릴 수 있다.
- 얼굴 파츠를 나중에 바꿔도 이미 그린 선과 되돌리기 기록은 유지된다.
- 캔버스 중앙에 매우 연한 반투명 십자선을 기본 표시해 얼굴 비례를 맞추기 쉽게 한다.
- 최종 저장물은 기존과 동일한 720×720 WebP 한 장이며, 얼굴 조합과 손그림만 포함한다.
- 참고 사진과 십자선은 화면에서만 보이고 저장 이미지에는 포함하지 않는다.

## 선택한 방향

얼굴 파츠를 캔버스 좌표에 맞춘 투명 WebP 레이어로 제공한다. 각 파츠 이미지는 처음부터 720×720의 동일한 기준점과 크기로 제작해 사용자가 직접 이동·확대·회전하지 않아도 자연스럽게 겹쳐지게 한다. 이 방식은 앵커 좌표 편집 UI가 필요 없고, 손가락으로 작은 요소를 조작해야 하는 문제도 피할 수 있어 모바일 첫 버전에 적합하다.

파츠 조합은 자유 그리기를 대체하지 않는 시작점이다. 사용자는 얼굴을 조합한 뒤 `이 얼굴로 시작하기`를 눌러 그리기로 돌아가거나, 얼굴 만들기를 사용하지 않고 현재처럼 빈 캔버스에 바로 그릴 수 있다.

## 레이어 구조

캔버스 영역은 아래에서 위 순서로 네 레이어를 사용한다.

1. **참고 사진:** 위치·배율·투명도를 조절할 수 있는 임시 레이어다. 최종 이미지에는 포함하지 않는다.
2. **얼굴 조합:** 선택한 얼굴형, 머리, 눈, 입, 소품을 순서대로 합성하는 바탕 레이어다. 최종 이미지에 포함한다.
3. **자유 그리기:** 기존 펜·지우개·색상·굵기·되돌리기 기능이 사용하는 캔버스다. 최종 이미지에 포함한다.
4. **십자선:** 캔버스 정중앙을 지나는 가로·세로 안내선이다. 입력을 가로채지 않으며 최종 이미지에는 포함하지 않는다.

최종 내보내기는 흰 배경, 얼굴 조합, 자유 그리기 순서로 720×720 오프스크린 캔버스에 합성하고 현재와 같은 WebP 압축 정책을 적용한다. 얼굴 조합만 있고 손그림이 없어도 유효한 그림으로 인정한다. 얼굴 조합과 손그림이 모두 없으면 기존 빈 그림 검사를 유지한다.

## 가이드 화면과 상호작용

상단 탭은 `그리기 · 가이드 · 편집`으로 표시한다. `가이드` 안에는 다음 두 선택지가 있다.

- **사진 참고:** 참고 사진이 등록된 경우에만 사용할 수 있다. 기존 보기·숨기기, 투명도, 확대, 이동, 위치 초기화를 그대로 제공한다.
- **얼굴 만들기:** 참고 사진 유무와 관계없이 항상 사용할 수 있다. 얼굴형, 머리, 눈, 입, 소품 카테고리를 짧은 한국어 라벨로 제공한다.

각 카테고리의 선택지는 큰 미리보기 버튼으로 표시하고 현재 선택을 테두리와 선택 상태 문구로 함께 알린다. 한 번 누르면 얼굴이 즉시 갱신된다. `랜덤 조합`은 모든 카테고리를 한 번에 선택하고, `얼굴 초기화`는 얼굴 레이어만 비운다. `이 얼굴로 시작하기`는 선택을 유지한 채 `그리기` 탭으로 돌아간다.

`그리기`의 `전체 삭제`는 자유 그리기 선만 지운다. 얼굴 조합은 `가이드`의 `얼굴 초기화`에서만 지워 예기치 않은 전체 손실을 방지한다. 자유 그리기의 실행 취소·다시 실행 기록과 얼굴 선택 상태는 서로 분리한다.

십자선은 기본으로 켜고 `가이드`에서 `중앙선 보기` 토글로 끌 수 있게 한다. 선은 종이와 그림을 방해하지 않는 중성색과 낮은 불투명도로 표시하며, 확대·전체 화면에서도 동일한 중앙을 유지한다. 이 설정은 현재 편집 세션에서만 유지한다.

## 얼굴 파츠와 이미지 제작

첫 버전은 다음 범위로 제한한다.

- 얼굴형 3종
- 머리 8종
- 눈 6종
- 입 6종
- 소품 6종

성별 카테고리는 두지 않고 서로 자유롭게 조합할 수 있게 한다. 파츠는 프로젝트의 기존 인물 드로잉과 어울리는 검은 연필·목탄 선, 완전한 투명 배경, 과하지 않은 표정으로 통일한다. 실제 자산은 이미지 생성 기능으로 제작하고, 투명 배경과 720×720 공통 정렬을 확인한 뒤 프로젝트 정적 자산으로 넣는다. 글자, 워터마크, 종이 배경은 파츠 이미지에 포함하지 않는다.

초기 진입 비용을 줄이기 위해 기본 조합에 필요한 이미지를 먼저 불러오고, 다른 카테고리 미리보기는 해당 카테고리를 열 때 불러온다. 선택된 파츠 원본은 최종 합성 전에 모두 로드되었는지 확인한다.

## 상태와 오류 처리

- 파츠를 불러오는 동안 해당 영역에 짧은 로딩 상태를 표시하고 중복 선택을 막는다.
- 일부 파츠 로드가 실패하면 현재 선택과 손그림은 유지하고 해당 파츠만 다시 시도할 수 있게 한다.
- 참고 사진이 없으면 `사진 참고`는 비활성 상태와 짧은 설명을 보이고 `얼굴 만들기`는 계속 사용할 수 있다.
- 저장 전 얼굴 합성에 실패하면 제출하지 않고 재시도 안내를 표시한다.
- 얼굴 선택과 십자선 설정은 Firebase에 별도로 저장하지 않는다. 최종 래스터 이미지 한 장만 기존 제출 흐름으로 전송한다.
- 완성 그림 가져오기는 기존 동작을 유지하며, 가져온 불투명 이미지가 얼굴 바탕을 가릴 수 있음을 가져오기 안내에 짧게 알린다.

## 모바일·접근성 기준

- 모든 선택 버튼과 토글은 최소 44×44px 터치 영역을 가진다.
- 각 파츠 버튼에는 카테고리와 번호를 포함한 접근 가능한 이름과 `aria-pressed` 상태를 제공한다.
- 카테고리 전환, 초기화, 랜덤 조합, 완료는 스와이프 없이 버튼만으로 수행할 수 있다.
- 십자선과 선택 상태는 색상에만 의존하지 않는다.
- 320px부터 650px까지 가로 스크롤 없이 한 열 흐름으로 축소하며, 하단 컨트롤은 기존 최대 650px 규칙을 유지한다.
- 모션 감소 설정에서는 파츠 전환 애니메이션을 사용하지 않는다.

## 변경 범위

### 포함

- 그림판 탭과 가이드 UI 재구성
- 얼굴 조합 상태와 독립 레이어
- 자유 그리기와 얼굴 조합을 합치는 WebP 내보내기
- 저장되지 않는 반투명 십자선과 세션 전용 토글
- 일관된 얼굴 파츠 이미지 자산 제작 및 적용
- 관련 단위 테스트와 모바일 브라우저 검증

### 제외

- 참고 사진을 분석해 자동으로 닮은 얼굴을 만드는 AI 기능
- 파츠별 이동·확대·회전·세부 색상 변경
- 사용자별 파츠 선택 저장 또는 계정 프로필화
- Firebase 문서 구조, 결제, 관리자 기능 변경
- 자유 그리기 모드 제거

## 테스트와 검수 기준

- 얼굴 파츠를 바꿔도 자유 그리기 픽셀과 실행 취소·다시 실행 기록이 유지되어야 한다.
- 얼굴만 선택한 상태는 저장할 수 있고, 얼굴과 손그림이 모두 없으면 저장할 수 없어야 한다.
- 내보낸 WebP의 레이어 순서는 흰 배경, 얼굴 조합, 자유 그리기여야 한다.
- 참고 사진과 십자선은 내보낸 WebP에 나타나지 않아야 한다.
- `전체 삭제`는 손그림만, `얼굴 초기화`는 얼굴 조합만 지워야 한다.
- 파츠 로드 실패와 재시도 상태에서 현재 그림을 잃지 않아야 한다.
- 320px, 390px, 650px 너비에서 탭·파츠 선택·십자선·전체 화면·제출 흐름을 모바일 Chrome으로 확인한다.
- 관련 단위 테스트, 린트, 타입 검사, 프로덕션 빌드가 통과해야 한다.
