# 소유자 그림 관리 및 자동 BEST 설계

## 목표

- 관리용 비밀번호로 인증된 소유자만 본인 그림을 수정한다.
- 공개 스케치북에 소유자 그림과 친구 그림 BEST 1~4를 함께 노출한다.
- 친구 그림이 네 개 이하인 동안에는 제출 순서대로 빈 BEST 순위를 자동 배정한다.
- 관리자가 지정한 BEST 순위는 이후 제출로 덮어쓰지 않는다.

## 사용자 흐름

1. 관리자는 `/m/[publicId]`에서 비밀번호 인증을 마친다.
2. 소유자 원본 카드의 `내 그림 수정하기`로 전용 편집 화면에 이동한다.
3. 기존 그림을 바탕으로 수정하고 `변경 저장하기`를 누르면 같은 스케치북의 소유자 이미지가 교체된다.
4. 공개 화면 `/s/[publicId]`는 소유자 그림을 별도 섹션에 표시하고, BEST 1~4를 순서대로 표시한다.

## 데이터 규칙

- 다섯 번째 그림이 되기 전까지만 저장 트랜잭션에서 현재 사용 중인 BEST 순위를 읽는다.
- 첫 네 그림에는 1~4 중 가장 낮은 빈 순위를 배정한다.
- 다섯 번째 그림부터는 관리자가 비워 둔 순위가 있어도 자동 배정하지 않는다.
- 수동 BEST 변경은 기존 동작을 유지하며 같은 순위의 이전 그림을 해제한다.
- 소유자 그림 수정은 관리 세션을 검증한 API만 허용하고, 최적화된 WebP를 정해진 소유자 경로에 저장한다.

## UX 원칙

- 소유자 그림 편집은 관리 대시보드와 분리해 실수로 다른 관리 작업을 건드리지 않게 한다.
- 저장 전에는 명시적인 저장 버튼을 제공하고, 저장 중·실패 상태를 텍스트로 알린다.
- 공개 화면에서는 소유자 그림과 친구 BEST의 주체를 제목으로 분명히 구분한다.
