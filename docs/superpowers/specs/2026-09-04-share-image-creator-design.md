# 공유 이미지 제작 기능 확장 설계

## 1. 목적과 사용자

스케치북 생성자가 친구들이 남긴 그림을 공유 가능한 이미지로 만드는 기능을 `베스트 이미지 제작`에서 `이미지 제작`으로 확장한다. 사용자는 관리 화면에서 한 장짜리 정사각형 이미지 또는 기존 BEST 4 이미지를 선택하고, 모바일 한 화면 흐름 안에서 제목·그림·디자인·워터마크·출력을 순서대로 처리한다.

성공 기준은 다음과 같다.

- 이미지 제작 진입 시 두 제작 유형을 바로 이해하고 선택할 수 있다.
- 이름 검색으로 원하는 친구의 그림을 빠르게 찾고, 같은 이름의 여러 그림 중 하나를 구분해 선택할 수 있다.
- 한 장 이미지와 BEST 이미지가 서로 다른 제목을 기억한다.
- 미리보기와 다운로드 결과가 같은 구성으로 출력된다.
- 기존 BEST 지정, 결제, 관리 세션, 공개 그림 노출 규칙을 그대로 유지한다.

## 2. 선택된 제품 방향

하나의 `/m/[publicId]/share` 제작 페이지와 하나의 공통 편집기에서 모드만 전환한다.

- `single`: 1080×1080 정사각형 한 장 이미지
- `best`: 기존 1080×1440 BEST 4 이미지

관리 화면의 `베스트 이미지 제작` 문구는 모두 `이미지 제작`으로 변경한다. 관리 화면에서 클릭하면 접근 가능한 모달을 열고 `그림 하나 제작하기`와 `BEST 이미지 제작하기`를 카드형 링크로 제공한다. 각 링크는 `/m/[publicId]/share?mode=single` 또는 `/m/[publicId]/share?mode=best`로 이동한다.

사용자가 모드 없이 `/share`에 직접 접근하면 동일한 선택 모달을 먼저 표시한다. 알 수 없는 `mode` 값도 선택 모달로 되돌려 잘못된 편집 상태가 생기지 않게 한다.

## 3. 화면 순서와 상호작용

두 제작 모드는 동일한 세로 순서를 사용한다.

1. 이미지 제목 입력
2. 그림 선택
3. 공유 이미지 디자인 선택
4. 실시간 미리보기
5. 워터마크 제거 결제 또는 적용 상태
6. PNG 저장

상단 헤더 제목은 `이미지 제작`으로 통일한다. 현재 모드는 헤더 아래에 `그림 하나` 또는 `BEST 4` 상태로 표시하고, `제작 유형 바꾸기` 버튼으로 선택 모달을 다시 열 수 있게 한다.

### 3.1 제목 입력

- 두 모드는 제목 값을 따로 저장한다.
- 기존 `storyHeading`은 BEST 제목으로 계속 사용해 기존 데이터를 마이그레이션하지 않는다.
- 새 `singleStoryHeading` 필드를 추가한다.
- 한 장 이미지의 초기 기본 제목은 `친구가 그린 나`로 한다.
- BEST 기본 제목과 최대 글자 수는 기존 상수를 유지한다.
- 제목 저장 API는 요청한 모드의 제목만 변경하며 다른 모드의 제목을 건드리지 않는다.
- 빈 제목은 저장하거나 출력할 수 없다.

### 3.2 한 장 이미지 그림 선택

선택 대상은 관리자가 열람할 수 있으면서 현재 공개 가능한 그림으로 제한한다.

- 친구 그림: `VISIBLE`이면서 `ACTIVE`인 그림
- 소유자 그림: 저장된 소유자 그림이 있을 때 별도 `내 그림` 카드로 제공
- BEST 선정 여부와 관계없이 선택 가능
- 차단, 삭제, 숨김 처리된 친구 그림은 검색 결과에서 제외

`내 그림` 카드는 검색 입력과 별도로 항상 먼저 표시한다. 친구 그림은 `그린 사람 이름을 입력해 주세요` 검색창에서 작성자 이름 일부를 입력하면 표시한다. 검색어 앞뒤 공백과 한글·영문 대소문자 차이를 무시하고 부분 일치로 검색한다. 검색어가 비어 있을 때는 전체 갤러리를 펼치지 않고 안내 문구만 보여준다.

동일한 작성자 이름의 그림은 모두 노출한다. 각 결과에는 그림, 작성자 이름, 작성 시각을 표시해 사용자가 구분할 수 있게 한다. 선택된 그림은 체크 아이콘, 전체 테두리, `선택됨` 텍스트를 함께 사용해 색상만으로 상태를 전달하지 않는다. 검색어를 바꿔 선택 카드가 결과에서 사라져도 현재 선택 요약은 유지한다.

그림이 한 장도 없으면 한 장 이미지 제작을 비활성화하지 않고 빈 상태와 공개 스케치북 공유 안내를 보여준다. 그림이 선택되기 전에는 미리보기 자리 표시자를 제공하고 PNG 저장 버튼을 비활성화한다.

### 3.3 BEST 이미지 그림 선택

기존 BEST 순위 데이터를 그대로 사용하며 제작 페이지에서 순위를 변경하지 않는다. 현재 `순위 정하러 가기` 링크를 유지한다. BEST가 한 장 이상 있으면 출력할 수 있고, 비어 있는 순위는 기존 `아직 선정 전` 자리 표시자를 사용한다. BEST가 하나도 없으면 PNG 저장을 비활성화하고 순위 관리로 이동하도록 안내한다.

## 4. 출력 이미지 구성

### 4.1 한 장 이미지

- 크기: 1080×1080 PNG
- 상단: 사용자가 작성한 제목
- 중앙: 선택한 그림을 자르지 않고 흰 종이 프레임 안에 `contain`으로 표시
- 그림 아래: `그린 사람 · {이름}` 또는 소유자 그림일 때 `{스케치북 이름} · 내 그림`
- 하단: 워터마크가 적용된 경우 기존 스케치북 워터마크
- 제외: BEST 배지, 공개 URL, 참여 CTA
- 파일명: `{스케치북 이름}-sketchbook-single.png`

### 4.2 BEST 이미지

기존 1080×1440 구성, 순위 배지, 공개 URL, 참여 CTA를 유지한다. 제목만 BEST 전용 저장값을 사용한다. 파일명은 `{스케치북 이름}-sketchbook-best.png`로 명확히 구분한다.

두 모드는 기존 공유 이미지 테마를 함께 사용한다. 미리보기와 Canvas 출력은 같은 레이아웃 상수와 데이터 모델을 사용해 위치·문구·워터마크 상태가 달라지지 않게 한다.

## 5. 워터마크와 결제

워터마크 제거 권한은 제작 유형과 무관한 기존 `watermarkFree` 권한을 그대로 사용한다.

- 한 번 구매하면 한 장 이미지와 BEST 이미지 모두에서 워터마크가 제거된다.
- 기존 1,000원 상품, 구매 API, 휴대전화번호, 동의, 결제 결과 흐름은 변경하지 않는다.
- 결제 팝업을 열었다가 닫을 때는 현재 편집 모드, 제목, 선택 그림, 테마를 유지한다.
- 실제 결제 요청은 기존처럼 페이앱 화면으로 이동한다. 결제 완료 뒤 제작 페이지에 다시 들어오면 저장된 제목과 워터마크 권한은 복원하고, 선택 그림과 테마는 기본 상태에서 다시 선택한다.
- 결제 팝업 문구의 `스토리 이미지` 표현은 `공유 이미지`로 일반화한다.

## 6. 컴포넌트와 데이터 경계

### 서버 페이지

`share/page.tsx`는 관리 세션을 검증하고 다음의 최소 데이터만 편집기에 전달한다.

- 스케치북 이름, 공개 경로, 워터마크 권한
- BEST 제목과 한 장 이미지 제목
- 소유자 그림 메타데이터와 관리 이미지 URL
- 공개 가능한 친구 그림의 ID, 작성자 이름, 작성 시각, BEST 순위, 관리 이미지 URL

검색은 최대 참여 한도 범위의 메타데이터를 대상으로 클라이언트에서 처리한다. 검색 결과에 들어온 그림만 렌더링해 불필요한 이미지 요청을 피한다.

### 클라이언트 구성

- `ImageModeChooser`: 제작 유형 선택 모달과 포커스 복귀
- `ShareImageComposer`: 모드, 제목, 테마, 선택 그림, 워터마크 상태 조정
- `DrawingPicker`: 내 그림 바로가기, 이름 검색, 결과 및 선택 상태
- `SingleImagePreview`: 정사각형 화면 미리보기
- `BestImagePreview`: 기존 BEST 4 미리보기
- `ShareImageMaker`: 모드별 Canvas PNG 출력
- `WatermarkPurchaseButton`: 기존 결제 동작 재사용

기존 `StoryImageComposer`와 `StoryImageMaker`는 역할이 넓어지므로 공유 이미지 명칭으로 변경하되, 결제나 스케치북 관리의 관련 없는 코드는 리팩터링하지 않는다.

## 7. 상태와 오류 처리

- 제목 저장 중: 저장 버튼 비활성화와 `저장 중` 표시
- 제목 저장 실패: 입력값 유지, 인라인 오류와 재시도 가능
- 검색 결과 없음: `{검색어} 이름으로 공개된 그림을 찾지 못했어요.` 안내
- 이미지 불러오기 실패: 실패한 카드와 출력 상태에 일반화된 오류 표시, 내부 오류 원문 비노출
- 출력 준비 중: 중복 실행 방지를 위해 저장 버튼 비활성화
- Canvas 미지원: 현재 일반 오류 문구 유지
- 결제 중: 기존 팝업 닫기 방지와 요청 중복 방지 유지
- 선택 그림이 이후 숨김·차단된 경우: 출력 요청에서 이미지 응답 실패를 감지하고 다시 선택하도록 안내

## 8. 반응형과 접근성

- 기존 최대 650px 단일 모바일 책 폭을 유지한다.
- 모드 선택 모달과 결제 모달은 키보드 포커스 가두기, Escape 닫기, 트리거 포커스 복귀를 지원한다.
- 모드 카드는 제목, 출력 비율, 설명을 함께 제공하며 카드 전체가 44px 이상의 링크 영역이 된다.
- 검색 결과는 320px 이상 2열, 그 미만 1열로 표시한다.
- 그림은 자르지 않고 항상 전체가 보이게 한다.
- 입력 라벨, 검색 결과 수, 선택 상태, 저장 상태를 스크린 리더가 읽을 수 있게 한다.
- 미리보기는 시각 콘텐츠와 별도로 현재 제목·선택 작성자·출력 크기를 접근 가능한 이름으로 제공한다.

## 9. 테스트 범위

### 단위 및 컴포넌트 테스트

- 모드 없는 접근과 잘못된 모드의 선택 화면 처리
- 두 제목의 독립 저장과 기존 BEST 제목 호환
- 부분 이름 검색, 공백 정규화, 동일 이름 복수 결과
- 공개 가능 상태 필터와 내 그림 선택
- 선택 유지, 빈 상태, PNG 버튼 활성 조건
- 한 장·BEST 미리보기의 제목, 작성자, 워터마크 상태
- 모드별 Canvas 크기, 파일명, 이미지 `contain` 배치
- 워터마크 제거 권한의 두 모드 공통 적용

### E2E 테스트

- 관리 화면 `이미지 제작` → 모드 선택 팝업
- 한 장 이미지: 이름 검색 → 동일 이름 결과 → 한 장 선택 → 제목 저장 → 정사각형 미리보기 → PNG 출력 준비
- BEST 이미지: 기존 순위와 별도 제목 유지 → 미리보기 → 출력
- 제작 유형을 전환해도 두 제목과 한 장 선택 상태가 섞이지 않음
- 320×568 및 390×667에서 가로 넘침과 주요 버튼 접근성 확인
- 결제 팝업이 두 모드에서 동일하게 열리고, 결제하지 않고 닫으면 현재 편집 상태를 보존

## 10. 범위 밖 항목

- 제작 페이지에서 BEST 순위 변경
- 여러 한 장 이미지를 한 번에 일괄 다운로드
- 사용자가 직접 이미지를 업로드하는 기능
- 정사각형 이미지 안의 요소 위치·폰트·색상을 개별 편집하는 기능
- 새로운 결제 상품 또는 가격 변경
- 공개 공유 링크의 썸네일 정책 변경

## 11. 구현 완료 조건

- 관리 화면에서 `이미지 제작` 선택 모달을 거쳐 두 모드에 진입한다.
- 한 장 이미지에서 이름 검색과 단일 선택이 동작하고 1080×1080 미리보기·출력 계약이 일치한다.
- BEST 기능의 기존 출력과 결제 동작에 회귀가 없다.
- 두 제목이 독립적으로 저장된다.
- 단위 테스트, 타입 검사, 린트, 프로덕션 빌드, 모바일 E2E가 통과한다.
