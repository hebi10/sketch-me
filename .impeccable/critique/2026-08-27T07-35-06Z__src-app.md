## Design Specificity Verdict

제품 고유성은 높다. 초상화 콜라주, Gaegu 손글씨, 종이 질감, 얇은 연필선과 단일 블루가 “친구들이 그린 나를 모으는 스케치북”이라는 목적에 묶여 있다. 자동 검출은 `src/app/globals.css`에서 79건의 advisory를 찾았고, 78건은 문서화되지 않은 font-size, 1건은 문서화되지 않은 색상(`#9a9892`)이었다. 대부분 직접적인 결함보다는 DESIGN.md 토큰 문서와 구현 간 간격이다. 브라우저 DOM 변형이 불가능해 사용자 화면 오버레이는 주입하지 못했으며, 390×844와 320×568 실측 및 정적 소스로 대체했다.

## Overall Impression

브랜드와 기능 범위는 MVP치고 상당히 완성도가 높다. 460개 단위 테스트, 서버 전용 Firebase 접근, WebP·썸네일·캐시, 관리자 운영 화면까지 있어 제한 베타를 시작할 기반은 충분하다. 가장 큰 기회는 기능 추가가 아니라 “만든 직후 공유 → 친구가 바로 참여 → 결과를 다시 공유” 전환을 짧게 만들고, 공개 비용·관리 권한을 운영 수준으로 잠그는 것이다.

## What's Working

1. 모바일 650px, 종이·연필·단일 블루라는 디자인 원칙이 랜딩부터 스토리까지 이어진다.
2. 빈 화면, 로딩, 오류, 정원 마감, 운영자 차단, 삭제 재확인 등 상태 범위가 넓고 접근성 기초가 좋다.
3. Firestore·Storage 기본 거부, 서버 권한 검증, 관리자 단일 계정, 이미지 크기 제한과 WebP·320px 썸네일, 5분 버전 캐시가 구현돼 있다.

## Priority Issues

### [P1] 모바일 그리기 작업성이 아직 안정적이지 않다

- 390px와 320px 실측에서 하단 도구 패널과 우측 고정 컨트롤이 약 19px 겹치고 오류 메시지도 패널 위에 겹친다.
- 720px PNG 데이터 URL 스냅샷을 획마다 무제한 누적해 긴 그림 세션에서 모바일 메모리가 커질 수 있다.
- 수정: 컨트롤 전용 열 또는 하단 통합 툴바, 비중첩 오류 영역, 이력 30~50단계 상한을 적용한다.
- Suggested command: `$impeccable harden`

### [P1] 핵심 바이럴 전환이 한 단계씩 늦다

- 생성 성공 뒤 유일한 CTA가 관리 화면이며 즉시 공유가 없다.
- 그림이 있는 공개 페이지에서는 참여 CTA가 전체 갤러리 뒤에 있다.
- 전환 분석 도구가 없어 생성→공유→그리기 시작→제출 이탈을 측정할 수 없다.
- 수정: 생성 완료의 기본 CTA를 네이티브 공유/링크 복사로, 공개 화면의 그리기 CTA를 상단 또는 하단 고정으로 옮기고 최소 이벤트 계측을 추가한다.
- Suggested command: `$impeccable clarify`

### [P1] 공개 비용·남용 방어가 운영 설정과 사용자 선의에 의존한다

- App Check는 기본 false이고 설정 누락 시 fail-open이다.
- 모의 구매는 참여 한도 상한이 없고 공개 그림 목록은 페이지네이션 없이 전부 읽고 렌더링한다.
- UI가 사용하지 않는 공개 원본 이미지 route와 no-store 참고 사진 route는 반복 Storage 다운로드 비용에 노출된다.
- 수정: 운영 배포에서 App Check 설정을 fail-closed 검증하고, 모의 구매 상한·갤러리 페이지네이션·불필요한 공개 원본 route 제거/권한화를 적용한다.
- Suggested command: `$impeccable harden`

### [P1] 4자리 관리 PIN과 소유자 mutation 보호가 공개 서비스 기준에는 약하다

- 실패 횟수 read/write가 트랜잭션이 아니고 IP별 잠금만 있어 병렬 요청·IP 변경에 약하다.
- 소유자 구매·보안 변경·그림 관리·전체 삭제 route에는 관리자 route와 같은 정확한 Origin 검사가 없다.
- 수정: 실패 카운트를 트랜잭션화하고 스케치북 단위 보조 제한을 추가하며, 관리 mutation에 공통 Origin/CSRF 검증을 적용한다. 장기적으로 6자리 이상 또는 계정/매직링크 복구를 검토한다.
- Suggested command: `$impeccable harden`

### [P2] 운영 약속과 데이터 생애주기가 수동 절차에 머문다

- 무료 스케치북 180일 자동 만료는 명시적으로 미구현이다.
- 실제 결제·환불·1년 보장·종료 안내를 실행할 결제 제공자와 사용자 연락 수단은 아직 없다.
- 예산, 오류율, App Check 활성화도 저장소가 아닌 수동 체크리스트다.
- 수정: 실제 결제 전에는 모의임을 유지하고, 공개 출시 체크리스트를 배포 게이트로 바꾸며 TTL/정리 작업은 실제 정책 결정 후 구현한다.
- Suggested command: `$impeccable document`

## Persona Red Flags

**Sam(접근성 의존 사용자)**: 모달 포커스·44px 터치·대비는 좋다. 반면 캔버스는 포인터 전용이고 참고 사진 이동의 키보드 대체 수단이 없으며 카드 오류가 작업 위치 근처에 연결되지 않는다.

**Casey(산만한 모바일 사용자)**: 긴 갤러리에서 참여 CTA를 놓치기 쉽고, 친구 그림 초안이 없어 새로고침 시 작업을 잃는다. 작은 화면에서는 도구와 우측 컨트롤이 겹친다.
